## 1. 一句话概况

- **项目**：TENET「信条」官方网站（xin-tiao.top）
- **品牌理念**：「服务用户，保护隐私，平台稳定」
- **设计语言**：Intelligent Minimalism（智能极简）
- **品牌强调色**：TENET 橙 `#D97757`
- **技术栈**：Astro 7 + Tailwind CSS v3，包管理器 Bun 1.4.0
- **语言**：中英双语（中文 `/`，英文 `/en`）
- **定位**：不是低价 API 中转站，而是逐步建立的 AI 服务生态入口


## 8. 已知问题 / 坑

1. **代理**：直连 GitHub 会 `Connection reset`，推送必须走 `127.0.0.1:7897`（仓库已配好 http.proxy）。
2. **沙盒/权限**：桌面快捷方式、`.gitconfig` 全局写入等操作需要授权。
3. **Git 身份**：官网仓库本地已配 `user.name=TENET`、`user.email=contact@xin-tiao.top`；换机器需重配。
4. **Bun 遥测**：构建前设 `ASTRO_TELEMETRY_DISABLED=1`，否则可能报遥测写权限问题。
5. **版本记录同步**：改完 `docs/03-版本记录.md` 要记得 commit + push（main 和 master 都要同步）。
6. **许可证**：LICENSE 为 PolyForm Noncommercial，禁止商用；README 已标注。
