# TENET 官网设计宪章（Design Constitution）

> 本文件是 TENET 官网的**长期设计规则真源**。
> 任何后续版本都必须参考本文件；若新需求与本宪章冲突，必须先提醒项目负责人，不得默默覆盖旧规则。

---

## 1. Brand Positioning（品牌定位）
- 品牌名：TENET「信条」；域名：xin-tiao.top
- 品牌理念：服务用户，保护隐私，平台稳定
- 长期方向：不是低价 API 中转站，而是逐步建立完整的 AI 服务生态
- 状态：早期创业阶段，单人开发 + AI 辅助，低成本长期迭代，必须实际上线可行

## 2. Design Language（设计语言）
- 核心：**Intelligent Minimalism（智能极简）**
- V1.2 视觉方向（已确认）：吸收参考站「编辑级高级感」：
  - 近黑白灰的克制配色 + 橙色只作点睛
  - 衬线标题（Noto Serif SC / Fraunces 精神）+ 无衬线正文 + 等宽 mono 标签
  - 发丝线 hairline、柔光托举阴影、expo-out 缓动
  - 动效克制、只在关键处极淡地动
- 严禁直接复制任何其他品牌的 Logo/图标/具体文案

## 3. Color（色彩）
- 基础色：白 `#FFFFFF` / 浅暖灰 `#FAFAF7` / 近黑 `#0A0A0A` / 次级 `#525252` / 弱化 `#767673`
- **TENET 橙 `#D97757`** 为唯一品牌强调色，只用于：Logo、主 CTA、hover、状态、关键视觉元素
- 橙色不铺满页面；大面积区域保持近黑白灰
- 暗色模式：V1 不启用

## 4. Typography（字体）
- 正文：`Noto Sans SC` / `Public Sans` / 系统无衬线
- 标题：`Noto Serif SC`（中文衬线）+ `Fraunces` 精神（英文衬线）——编辑/杂志感
- 标签：`IBM Plex Mono` / `JetBrains Mono` 等宽，`uppercase` + `letter-spacing 0.14em`（mono-label）
- 标题 `font-weight 560` + `letter-spacing -0.015em`

## 5. Spacing / Grid
- 内容最大宽度 `1200px`；区块垂直间距 `80–112px`（桌面）
- 卡片圆角体系：8/12/16/20/24px + 胶囊 `9999px`

## 6. 边框 / 阴影 / 层次
- 边框：发丝线 hairline（`rgba(10,10,10,.04~.08)`）
- 阴影：柔光托举式（负扩散）：`0 18px 40px -20px`、`0 24px 48px -12px`
- 层次：毛玻璃（backdrop-blur 12px）用于导航/浮层；暖色顶部光晕 `radial-gradient(120% 70% at 50% 0%, rgba(217,119,87,.10))`

## 7. Motion（动效）
- 缓动统一：`cubic-bezier(.16, 1, .3, 1)`（expo-out）——快进慢出
- 进入动画：scaleIn（0.95→1 + 淡入）/ slideIn（14px 滑入 + 淡入）
- 呼吸/脉冲极淡：`opacity .18~.55` 级别
- 滚动渐入（IntersectionObserver）+ 尊重 `prefers-reduced-motion`
- 禁止：大量持续动画、影响阅读的背景动画、炫技

## 8. Components
- 导航：固定居中悬浮胶囊（玻璃）+ 近黑白 + 登录按钮橙色点睛
- 按钮：主 CTA 黑色实心（Hero/定价）或橙色（登录/底部 CTA）；次按钮描边
- 卡片：白底 + hairline + 柔光托举阴影 + hover 上浮
- Footer：品牌 + 理念 + 导航/协议/联系方式 + 语言切换

## 9. 文案调性（Copywriting）
- 高级、克制、编辑感；不堆砌、不夸大
- 标题短而有分量，如「把全球最好的 AI 模型，接到你的产品里」
- 正文简洁、可信、温暖

## 10. Responsive / Accessibility
- 断点：移动 <768 / 平板 768–1024 / 桌面 >1024
- 移动端单列 + 汉堡导航 + 触控高度 ≥44px；不横向滚动
- 语义化 HTML、focus-visible、reduced-motion 尊重

## 11. Do / Don't
- Do：近黑白灰 + 橙色点睛；衬线标题；发丝线；柔光托举；expo-out；克制动效
- Don't：大面积橙色；复制他人 Logo/文案；满屏动效；模板化渐变卡片堆叠
